# 心情记录本

用纯 Win32 API 写的单文件桌面程序：**选一个心情标签 → 打个 1~10 分 → 点「记下来」**，每次记录追加一行到同目录的 `mood_log.csv`。

不联网、不登录、无账号，数据只在你自己的磁盘上。

## 功能

- **12 个心情标签**：开心、平静、兴奋、感激、放松、专注、疲惫、焦虑、低落、生气、孤独、迷茫（2 行 × 6 列，单选）
- **1~10 分评分**：10 个胶囊按钮，单选
- **三项统计**：底部实时显示「今天已记 N 条 · 累计 N 条 · 连续记录 N 天」
- **输入校验**：缺标签或缺分数只弹提示，不写文件；写入失败会明确报错并保留当前选择
- **自动建文件**：首次运行创建 `mood_log.csv`，UTF-8 带 BOM，Excel / WPS 双击可开
- **自绘界面**：GDI 全自绘胶囊按钮，双缓冲防闪烁；窗口固定 560 × 452，可最小化、不可拉伸

## 编译

无第三方依赖，只需一个 Windows C 编译器。

```bash
gcc -O2 -municode -mwindows -Wall -o mood.exe mood.c
```

- `-municode` 不能省：入口是 `wWinMain`，漏掉会链接失败；`-mwindows` 避免弹控制台。
- 若界面中文乱码，加 `-finput-charset=UTF-8 -fexec-charset=UTF-8` 重编。
- MSVC 同样可编：加 `/utf-8` 并把子系统设为 `/SUBSYSTEM:WINDOWS`。

## 使用

1. 把 `mood.exe` 放进你希望存数据的目录（CSV 走相对路径，写在当前工作目录；双击启动时即 exe 所在目录）。
2. 运行 → 选标签 → 选分数 → 点「记下来」→ 弹出回执，选择自动清空。

同一天可记多条，程序不去重。**连续记录天数**按「出现过记录的日期」往前逐日累计，今天没记则从昨天起算，遇第一个空日期即停（最多回溯 3650 天）。

## 数据格式

```csv
date,score,mood
2026-11-11,7,开心
2026-11-11,6,平静
```

| 列 | 取值 | 说明 |
| --- | --- | --- |
| `date` | `YYYY-MM-DD` | 本地日期 |
| `score` | `1` ~ `10` | 心情分数 |
| `mood` | 12 个标签之一 | UTF-8，无引号无逗号，不与分隔符冲突 |

## 限制

- 只能**追加**，程序内不能编辑或删除（清理请直接用 Excel / 文本编辑器改 CSV）
- 没有历史列表、图表、日历视图、导出导入、提醒、多用户、云同步
- 仅支持 Windows（依赖 `windows.h` 与 Win32 消息循环）
- 启动时会把 CSV 的日期列全读进内存，上限 40000 条（`MAX_RECORD`）
